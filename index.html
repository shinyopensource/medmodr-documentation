What is MedModr?

MedModr is a free, browser-based statistical tool for conducting mediation, moderation, and conditional process analyses. All computation happens entirely inside in the user's browser. There is no installation, no server, no data upload to any external service.

Fully Portable — Works Offline

MedModr runs as a single self-contained HTML file. Once loaded in any browser, save the page (Ctrl+S / Cmd+S) for permanent offline use. Copy it to USB drives, email it, or share via cloud storage. No internet connection is required.

No Installation

Works on Windows, Mac, Linux, Chromebooks, tablets. Just open in any modern browser (e.g., Chrome, Firefox, Edge, or Safari).

100% Private

Data never leaves the user's device. All computations run locally in the browser using JavaScript matrix algebra.

Import CSV or Excel

Upload .csv, .xlsx, or .xls files. The built-in data processing pipeline handles missing values, screening, and variable selection.

Export to Word

Download complete analysis results as a formatted Word document (.doc) with tables, summaries, and APA-style write-ups.

Key Features

9 Analysis Types

From simple mediation to moderated serial mediation and three-way interactions.

Bootstrap CIs

Percentile bootstrap (up to 10,000 samples) or Bias-Corrected (BC) bootstrap for indirect effects.

Interactive Path Diagrams

Auto-adjusting, color or B&W, downloadable PNG, with coefficient overlays.

Simple Slopes Plots

Annotated plots at −1SD, Mean, and +1SD of the moderator. Downloadable hi-res PNG.

Multiple Imputation

7 missing data methods including PMM, Hot Deck, EM algorithm, and regression imputation.

Data Screening

Outlier detection (4 methods), normality checks, correlation matrices, and diagnostic plots.

Categorical Variables

Built-in dummy coding modal. Select reference categories and encode with one click.

Both Coefficients

Every regression table shows unstandardized (b) and standardized (β) coefficients with VIF.

Export Results

Single or all results exported to a formatted Word document with APA-style summaries.

App Workflow at a Glance

2

Click Proceed to Analysis on the Finalize step (Step 7). This transfers your cleaned data directly to the Statistical Analysis page.

3

Select variable chips from the Available Variables pool and assign them to X, M, M2, Y, W, or Covariates boxes.

4

5
Run & Export

Click ▶ Run Analysis Browse results, view path diagrams and slopes plots, then export to Word.

Data Processing (Step-by-Step)

The Data Processing page guides you through a 7-step pipeline to prepare your data. You can skip directly to Step 7 (Finalize) and proceed to analysis if your data needs no cleaning.

Step 1 — Upload Data

Click Select File or drag and drop your file onto the upload zone. MedModr accepts CSV (.csv) and Excel (.xlsx, .xls) files. Your first row must be a header row containing variable names.

File Requirements

CSV files work fully offline. Excel files require an internet connection the first time (to load the SheetJS library). Once SheetJS is cached by the browser, Excel files also work offline.

How to Handle Missing Values in Your File

Before uploading, type NA in every empty cell in your spreadsheet. This is the only supported approach. MedModr uses NA to detect and count missing values. A blank cell may not be reliably recognised as missing and could cause incorrect results.

Do not fill missing cells with values like 999, -1, or 0 as stand-ins. MedModr will treat those as real data, which will distort your analysis.

After upload, the app shows a file info panel with row count, column count, and the number of categorical vs numeric variables detected. Click Next: Select Variables to continue.

Step 2 — Select Variables

A two-panel layout shows Available Columns on the left and Selected Variables on the right. Click Add → next to each variable you want to include, or use Add All to include everything. Use Remove to exclude a variable.

Variables automatically detected as categorical (containing text values) are shown with a tag icon.

Click Next: Preview Data when you have selected all variables you need.

Step 3 — Preview Data

A scrollable table shows all rows and columns of your selected data. Missing values are highlighted in red as NA. Below the table, a summary statistics panel shows N, Mean, SD, Min, Max, and missing counts for each numeric variable, and level counts for categorical variables.

From here you can either click Skip to Analysis (bypasses missing data and screening steps), or click Next: Missing Data Summary to continue the full pipeline.

Step 4 — Missing Data Summary

A table shows each variable with its valid N, missing N, and missing percentage. Variables with high missingness are highlighted in amber (5–20%) or red (>20%).

Three action buttons are available:

  • Apply Imputation — proceeds to Step 5 to choose an imputation method.
  • Listwise Deletion — removes all rows with any missing value immediately.
  • Proceed — skips imputation and proceeds to Step 6 with missing values intact. Some analyses may not run cleanly with missing data.

Step 5 — Imputation

Seven imputation methods are available. Select one by clicking its button, then click Apply Imputation.

MethodBest Used WhenNotes
Mean ImputationMissingness <5%, MCARBiases standard errors downward; use sparingly.
Median ImputationSkewed data, <5% missingMore robust than mean for non-normal distributions.
Mode ImputationCategorical or binary variablesReplaces with most frequent value.
Multiple Imputation (PMM)Any missingness levelRecommended. Predictive Mean Matching — finds observed donors by predicted values. Preserves distributions and uncertainty.
Hot DeckNon-normal dataFinds the nearest complete case by Euclidean distance; copies its value.
Regression ImputationMAR dataPredicts from other variables; adds stochastic residual noise to avoid determinism.
EM AlgorithmMultivariate normal, monotone missingIterative expectation-maximization over joint covariance structure.

After imputation, imputed cells are highlighted in yellow in Step 7. Exported CSV files mark imputed values with an asterisk (*). Click Next: Data Screening to continue.

Step 6 — Data Screening

Five screening tabs are available. Run each as needed before finalizing your data.

OutliersFour detection methods: Z-Score (±3), IQR (1.5×), MAD (3×), and Percentile (1st/99th). Switch methods using the toolbar buttons. Flagged outlier values and row numbers are shown.
NormalitySkewness and excess kurtosis for each numeric variable. Values near 0 indicate normality; |skewness| >2 or |kurtosis| >7 may indicate non-normality.
CorrelationBivariate correlation matrix for all numeric variable pairs. Choose Pearson (r), Spearman (ρ), or Kendall (τ). Significance stars (* p<.05, ** p<.01, *** p<.001) are shown.
Sample SizeMinimum N recommendations for each analysis type (Simple Mediation ≥50, Serial ≥100, Moderation ≥80, Moderated Mediation ≥200) compared against your actual N.
Diagnostic PlotsHistogram and Q-Q plot for each numeric variable rendered on HTML5 canvas. Individual plots can be downloaded as PNG files.

Step 7 — Finalize

A full table of your final clean dataset is shown, with imputed cells highlighted in yellow. Two buttons are available:

  • Export CSV — downloads a CSV file. Imputed cells are marked with * in the exported file, and a note at the bottom records which imputation method was used.
  • Proceed to Analysis — sends the cleaned dataset to the Statistical Analysis page and switches the sidebar navigation automatically.

Running Statistical Analysis

The Statistical Analysis page has a single panel: Variable Assignment. All analysis types are run from this same interface.

Step 1 — Assign Variables to Roles

The Available Variables pool shows all variables from your dataset as clickable chips. Click one or more chips to select them (they turn green), then click one of the Assign to… buttons to place them in a role box.

M2 Mediator 2Second mediator (serial chain)Serial Mediation, Moderated Serial Mediation

W ModeratorModerator (or both moderators for 3-way)Moderation, Moderated Mediation, Moderated Moderation, Moderated Serial Mediation
Cov CovariatesControl variables (any number)All analysis types
Moderated Moderation (3-way): Two Moderators in the W Box

For Moderated Moderation, assign both moderator variables to the W box. The first variable assigned becomes W and the second becomes Z (the moderator of the moderator).

Remove a specific variable from a role by clicking the ✕ next to its name inside the role box. Click the Clear button on a box header to empty that entire box. The red 🗑 Clear All button resets every box at once (a confirmation dialog appears first).

Step 2 — Handle Categorical Variables (if any)

If any variable in your role boxes contains text (e.g., "male", "female", "treatment", "control"), a Handle Categorical Variables button appears in the options row. Click it to open the encoding modal where you can:

  • Select a reference category for each categorical variable (coded as 0).
  • Choose which levels to include as dummy variables.
  • Click Apply Encoding to replace the original variable with 0/1 dummy variables in all role boxes.

A Reset Encoding button appears after encoding to restore the original categorical variable if needed.

Step 4 — Run Analysis

Click ▶ Run Analysis. A brief loading indicator appears. When results are ready, the page scrolls automatically to the Descriptive Statistics table. If multiple combinations of variables are run (e.g., 2 X variables × 3 Y variables = 6 results), a navigation bar appears at the top of the results area with Previous / Next, Show All Results, and Export All to Word buttons.

2
Assign variables

Set options

4
Run analysis

What You Get

Descriptive Statistics Path Diagram (interactive) a-Path Table (X → M) b-Path Table (X, M → Y) Total Effect Table (X → Y) Effects Summary (c, c', a×b) Bootstrap CI for indirect effect Sobel test (if no bootstrap) APA-style Summary
Interpreting Mediation

If the bootstrap CI for the indirect effect (a×b) excludes zero, the indirect effect is statistically significant. Full mediation occurs when the indirect effect is significant and the direct effect (c′) is not. Partial mediation occurs when both are significant.

Multiple combinations: If you assign multiple X and/or Y variables, MedModr runs a separate Simple Mediation for every X × M × Y combination and provides navigation between results.

What You Get

Interpreting Moderation

If the interaction coefficient (b₃, X×W) is statistically significant, moderation is present. This means the effect of X on Y changes across levels of W. Inspect the simple slopes table to understand the direction and magnitude of X's effect at low, mean, and high values of W.

Key Statistic: Index of Moderated Mediation (IMM)

The IMM quantifies how much the indirect effect changes per one-unit increase in W. A bootstrap CI that excludes zero confirms statistically significant moderated mediation. Then inspect the conditional indirect effects table to see the magnitude of the indirect effect at Low, Mean, and High W.

The three-way interaction coefficient (X × W × Z) is the focal statistic. A significant three-way interaction indicates moderated moderation — the moderating effect of W on the X→Y relationship itself changes across levels of Z.

Interpreting & Exporting Results

Every analysis produces a standardized output structure, always beginning with Descriptive Statistics and ending with an APA-style plain-language summary.

Regression Tables

Every regression table in MedModr reports both unstandardized (b) and standardized (β) coefficients, along with SE, t, p, LLCI, ULCI, significance stars, and VIF (Variance Inflation Factor) for multicollinearity diagnostics.

  • b — unstandardized coefficient (raw scale of the variables).
  • β — standardized coefficient (obtained by z-scoring all variables and re-running the same regression). Allows comparison across predictors in different units.
  • VIF — values >5 indicate potential multicollinearity concern; values >10 are considered serious.
  • Stars — * p<.05, ** p<.01, *** p<.001.

Effects Summary Table

At the bottom of each analysis is an Effects Summary showing total effect (c), direct effect (c′), and all indirect effects in a single table for easy comparison. Bootstrap CIs or Sobel test results are shown here.

Path Diagrams

Most of the analysis types produce an interactive path diagram below the Descriptive Statistics table. The diagram auto-adjusts to fit any variable name length. Click View Full-Screen Diagram to open the full-screen modal with these customization options:

Simple Slopes Plots

Available for Simple Moderation, First Stage Moderated Mediation, Second Stage Moderated Mediation, Both Stages Moderated Mediation, and Moderated Moderation. The plot shows three regression lines — one each for Low (−1SD), Mean, and High (+1SD) of the moderator W.

Inline plot controls:

  • Legend (Top-Right) / Annotations on Lines — switch how line labels are displayed.
  • Show/Hide p-values — include significance stars and p-values in labels.
  • Publication Ready / Default Style — toggle a clean white B&W theme.
  • Color pickers — individually change the color of each slope line.
  • Full Screen — open the plot in a large modal.
  • Download PNG — saves a 1800×1080 pixel PNG.

Exporting Results

Two export options are available after running analysis:

  • Export to Word (single result) — appears as a green button when only one result is present. Downloads the current result as a .doc file.
  • Export All to Word — available in the multi-result navigation bar when multiple variable combinations were run. Downloads all results combined into a single document.

The Word document includes: a header with the app name, version, analysis configuration, and generation date; all regression tables; effects summaries; APA-style interpretation paragraphs; and a citation block at the end.

Covariates (Control Variables)

Any number of control variables can be assigned to the Covariates box. They are automatically included in all regression models in the analysis chain (a-path model, b-path model, total effect model).

Covariate Centering

Covariates are mean-centered internally before entering any model. This improves interpretability of the intercept and reduces multicollinearity with interaction terms. The centering is applied to the analytical computations only and the original data is not modified.

Mean Centering Options

For analysis types that involve interaction terms (moderation, moderated mediation, moderated moderation, moderated serial mediation), three centering strategies are available in the options row:

  • No centering — raw variables enter the model. Interaction = raw X × raw W.
  • Continuous-only centered — only continuous variables are mean-centered. Binary (0/1) variables remain raw. Interaction = centered_X × centered_W.
  • All variables centered — all predictors are mean-centered including binary variables. Interaction = centered_X × centered_W.

Simple slopes tables always use mean-centered W values regardless of the centering option selected, to ensure the slopes at −1SD, Mean, and +1SD are correctly computed relative to the moderator mean.

Bootstrap Confidence Intervals

Bootstrap CIs are computed for all indirect effects: simple indirect effects (a×b), specific serial indirect effects, conditional indirect effects at levels of W, and the Index of Moderated Mediation (IMM).

Two bootstrap methods are available:

  • Percentile (default) — uses the raw percentiles of the bootstrap distribution. If a CI excludes zero, the effect is significant at α = 1 − confidence level.
  • Bias-Corrected (BC) — corrects for systematic bias in the bootstrap distribution using the proportion of bootstrap estimates below the observed estimate. Slightly more powerful but can be anti-conservative under certain conditions.

Recommended: 5,000 samples (Percentile) for stable CIs.

MedModr vs PROCESS Macro

MedModr implements the same mathematical framework as Hayes' PROCESS macro — OLS regression via matrix algebra, percentile bootstrap, and the conditional process modeling approach from Hayes (2022). The two tools agree within rounding error on all point estimates.
