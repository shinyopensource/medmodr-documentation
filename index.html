MedModr

Mediation, moderation and conditional process analysis in your browser

A free, open-source, browser-based tool for mediation, moderation, and moderated mediation analysis. It implements 92 PROCESS-equivalent models with bootstrap standard errors and confidence intervals, with all computations performed locally in your browser.

Use MedModr online See on GitHub Video tutorial Download Cite

Overview

Researchers, educators, and students who wish to apply mediation, moderation, and conditional process models often face practical barriers. These include installing and configuring statistical software or macros, troubleshooting installation errors and compatibility issues, obtaining licenses, meeting the cost of commercial software or recurring subscriptions, and writing code in script-based environments.

MedModr was developed in response to these challenges. It is a peer-reviewed statistical software, described in an article published in SoftwareX (Elsevier; see Citation), and a free, open-source, browser-based application written purely in JavaScript and designed for mediation, moderation, and conditional process analysis. It addresses the accessibility gap in advanced statistical modeling by eliminating the need for licensed software, local installation, programming expertise, or account registration. As a result, researchers, educators, and students can perform sophisticated analyses entirely within their web browser, with all computation occurring locally to ensure data privacy and security. Because MedModr runs entirely in a modern web browser, it is platform-independent and can be used on laptops, desktops, tablets (including iPads and Android tablets), and mobile devices across operating systems such as Windows, macOS, Linux, ChromeOS, iOS/iPadOS, and Android, without any installation.

Beyond accessibility, MedModr implements analytical models equivalent to those available in the PROCESS macro, encompassing mediation, moderation, and a wide range of moderated mediation variants. It generates comprehensive outputs, including regression tables, bootstrap standard errors and confidence intervals, standardized and unstandardized coefficients, interactive path diagrams, and simple slopes plots for applicable models. Built-in data screening, missing-data imputation, and dummy-coding capabilities further streamline the research workflow, from data preparation to the generation of publication-ready results. Regression diagnostics, a custom regression builder, robust standard errors, adjustable decimal places, and pairwise comparisons of indirect effects are also available.

Recommended browser webpage zoom

MedModr is a browser-based application. For optimal viewing and usability on medium or small laptop screens, reducing the browser webpage zoom to 90% or 80% instead of the default 100% is recommended. Use Ctrl + − (Windows/Linux) or ⌘ + − (macOS) to zoom out, and Ctrl/⌘ + 0 to reset.

Key Features

Analytical Models

MedModr currently supports 92 analytical models (Models 1–92) encompassing simple mediation, parallel mediation, serial mediation, simple moderation, double moderation, moderated moderation, first-stage, second-stage, and both-stage moderated mediation, as well as a wide range of moderated mediation variants. The current set covers a broad range of conditional process analysis applications in the health, social, behavioral, and educational sciences. See Analysis Types & Variable Assignment for the complete and current list of supported models.

The number of moderators or mediators you can assign depends on the model. The table below gives the supported range for each model.

Bootstrap Confidence Intervals

MedModr computes bootstrap confidence intervals for conditional and indirect effects using up to 10,000 resamples with either the Percentile or Bias-Corrected (BC) method. Bootstrap standard errors and confidence intervals are provided for all applicable estimates. The application uses the Mulberry32 pseudorandom number generator with a fixed seed (default = 12345), ensuring fully reproducible results across operating systems, browsers, and devices.

Interactive Path Diagrams

Auto-generated SVG path diagrams with coefficient overlays are available for applicable models. Users can toggle color schemes, show or hide values and p-values, switch between unstandardized (b) and standardized (β) coefficients, rename variables, and export diagrams as high-resolution PNG or SVG for publication.

Simple Slopes Visualization

Interactive Canvas-based simple slopes plots are available for applicable moderation and moderated mediation models, displaying the moderator's effect. Users can export plots as high-resolution PNG files for publication.

Moderator Probing Strategy

For all moderation and moderated mediation models, users can choose between two probing strategies for the moderator: Mean ± 1 SD (the default) and Percentile (16th / 50th / 84th). The percentile strategy is recommended when the moderator is skewed or non-normally distributed. The selected strategy is applied consistently across conditional effects tables, simple slopes plots, summary paragraphs, and indices of moderated mediation where applicable.

Missing Data Handling

Seven imputation methods are available for managing incomplete data: mean, median, mode, Predictive Mean Matching (PMM), hot-deck imputation, regression-based imputation, and the Expectation-Maximization (EM) algorithm. The application also supports custom missing-value codes (e.g., −999 and NA) and listwise deletion, providing flexible options for handling missing data according to the requirements of the analysis.

Data Screening and Quality Assessment

Built-in data screening tools enable direct in-browser data editing, outlier detection using four methods (Z-score, IQR, MAD, and percentile), and normality assessment based on skewness and kurtosis. Users can also generate correlation matrices using Pearson, Spearman, or Kendall correlation coefficients. Histograms and Q-Q plots provide additional visual tools for assessing data quality and distributional characteristics, with all screening outputs available for export as PNG files.

Categorical Variable Encoding

The application includes integrated dummy-coding functionality for categorical variables. Users can select a reference category and encode categorical variables with a single click, eliminating the need for manual recoding. A Reset Encoding option allows users to restore the original variable coding at any time.

Standardized and Unstandardized Coefficients

Regression tables for mediation models report both unstandardized (b) and standardized (β) coefficients, along with Variance Inflation Factor (VIF) statistics for assessing multicollinearity. Moderation and moderated mediation outputs report unstandardized coefficients and VIF statistics.

File Formats and Offline Functionality

CSV files are processed entirely offline without requiring an internet connection. Excel (.xlsx) files require a one-time internet connection to load the SheetJS library; thereafter, all data processing is performed entirely offline.

Results Export

Analysis results can be exported as formatted Word (.doc), PDF, HTML, or CSV documents suitable for publication or presentation. The Export All to Word function compiles results from multiple variable combinations into a single comprehensive document, streamlining the preparation of results for reporting and dissemination.

Regression Diagnostics

Click the Diagnostics button next to any regression table to open a comprehensive diagnostic report for that model. The report includes descriptive statistics, dominance analysis matrices, all-subsets regression results, residual diagnostic plots (histogram, normal Q–Q plot, scatter plot, residuals vs. fitted, scale-location, and residuals vs. leverage), residual statistics, residual skewness and kurtosis, Bonferroni-corrected p-values for the largest studentized residual, influential observations, the Breusch–Pagan test for heteroskedasticity (normal and robust versions), variable intercorrelations (Pearson, Spearman, and Kendall), and influence and outlier diagnostics (Mahalanobis distance, Cook’s distance, and centered leverage values). Every part of the report can be exported to Word.

Fit Model (Custom Regression)

Use Fit Model to build any OLS or logistic regression by combining predictors. Add your own interaction terms, queue multiple models, and run them all at once, with a full results table and diagnostics returned for each model. When you include interaction terms, you also get conditional-effect tables to interpret how the effect changes across moderator values.

Standard Errors: OLS and Robust (HC0–HC4)

Choose between classical OLS standard errors and heteroskedasticity-consistent (robust) standard errors, HC0 to HC4. The coefficients stay the same. The standard errors, t or z statistics, p-values, confidence intervals and F test are recomputed. This option applies to regression tables only.

Adjustable Decimal Places

Choose how many decimal places your results show, from 1 to 10. The setting applies to the output on screen, to downloaded files, and to regression tables you copy, so the numbers are ready to use in your manuscript or report without further formatting.

Pairwise Comparison of Indirect Effects

In multi-mediator models (Models 4, 6, 80, 81 and 82), turn on the Show pairwise comparison toggle to see contrasts between every pair of specific indirect effects. Each contrast comes with its bootstrap standard error and confidence interval, so you can test whether one indirect pathway is significantly stronger than another.

How It Works

MedModr follows a straightforward two-stage workflow designed to guide users from raw data through analysis to publication-ready results.

Stage 1: Data Processing

Detailed Steps

1Upload Data
2Select Variables
3Preview Data
4Missing Data Summary
5Choose Imputation
6Data Screening
7Finalize

Only the data upload and variable selection steps are mandatory; the remaining steps are optional but recommended for ensuring data quality and appropriate preprocessing.

Stage 1 workflow — data upload, preview, and screening prior to analysis.

Stage 2: Statistical Analysis

  1. Variable Specification: Assign dependent, independent, mediator(s), moderator(s), and covariate variables according to the selected analytical model.
  2. Model Selection: Choose from the full library of analytical models equivalent to those available in the PROCESS macro.
  3. Analysis Configuration: Specify bootstrap resampling parameters, confidence level, the type of standard errors (OLS or robust HC0–HC4), the number of decimal places (1–10), and other analysis preferences.
  4. Results Review: Examine comprehensive output, including regression tables, coefficients, bootstrap confidence intervals, and other model-specific results. Use the Diagnostics button beside any regression table for further checks.
  5. Export: Generate formatted Word, PDF, HTML, or CSV documents for publication or presentation.
Stage 2 results screen — APA regression tables

Notes

Variable notation:

  • W — Requires one moderator variable (W).
  • W, Z — Requires two moderator variables (W and Z).
  • M — Assign all mediators to the M box for every model. The app automatically detects the number of mediators and configures the appropriate parallel or serial structure.

You can add any number of covariates (Cov) to control for confounding variables in all analysis types.

Moderator Probing: For moderation and moderated mediation models, you can choose between Mean ± 1 SD (default) and Percentile (16th / 50th / 84th) probing. This option is not available for pure mediation models (Models 4, 6, 80, 81, and 82), which do not involve a moderator.

Testing, Bug Reports, and Feedback

Although the software has been fully tested, bugs and technical issues cannot always be completely avoided. If you encounter any bugs, errors, or unexpected behaviour, or if you have technical questions, need assistance, or wish to provide feedback, please contact me using the details in the Developer section. Your feedback is valuable in helping identify issues and continuously improve the software. Reported bugs and issues will be addressed as soon as possible.

What to Include in a Bug Report
  • The analytical model being used.
  • Browser and version (e.g., Chrome 125, Firefox 127).
  • A clear description of the expected versus actual behavior.
  • An anonymized sample dataset that reproduces the issue, if available.
