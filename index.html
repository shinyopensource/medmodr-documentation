MedModr

Mediation & Moderation Analysis Tool — browser-based, free, and open source

Version 2.0 Free & Open Source MIT License
Launch App Source Code 📥 Example Dataset

Overview

MedModr is a free, browser-based statistical tool for conducting simple mediation, serial mediation, moderation, and moderated mediation (conditional process) analyses. All computation runs entirely in your browser; no installation, no server, no data upload.

🔒 Privacy Guarantee

All data processing occurs client-side in your browser. No data is ever sent to any server. You can disconnect from the internet after the page loads and still run complete analyses.

Methodological Framework

MedModr follows the regression-based approach detailed in Hayes (2022) Introduction to Mediation, Moderation, and Conditional Process Analysis. It implements Ordinary Least Squares (OLS) regression via matrix algebra, providing unstandardized (b) and standardized (β) coefficients, bootstrap confidence intervals for indirect effects, and interactive visualizations.

Simple Mediation (X → M → Y)

Tests whether the effect of an independent variable X on outcome Y is transmitted through a mediator M. Output includes the a-path (X→M), b-path (M→Y), direct effect c′, total effect c, indirect effect (a×b), Sobel test, bootstrap CI, and an interactive path diagram.

1
Select Simple Mediation tab

Click Simple Mediation (X → M → Y).

2
Enter X, M, and Y

Provide names and data for all three variables. All must have the same N.

3
Add covariates (optional)

First line = names, subsequent lines = values.

4
Set options & run

Choose confidence level and bootstrap samples. Click Run Analysis.

Mathematical Formulas

a-path (X → M): M = i₁ + a·X + e₁ b-path (M → Y): Y = i₂ + c′·X + b·M + e₂ Total effect (c): Y = i₃ + c·X + e₃
Indirect Effect: IE = a × b Sobel Standard Error: SE = √(b²·SEₐ² + a²·SE_b²) Sobel z-test: z = IE / SE p-value: p = 2 × [1 − Φ(|z|)]
Bootstrap Percentile CI (B = 1,000–10,000): 1. Draw B samples with replacement (size n) 2. For each sample b, compute θ̂ᵦ = aᵦ × bᵦ 3. Sort θ̂(1), θ̂(2), …, θ̂(B) 4. 95% CI = [θ̂(0.025×B), θ̂(0.975×B)]
📚 Mediation Inference

If the bootstrap confidence interval for the indirect effect excludes zero, the indirect effect is statistically significant at α = 0.05. Mediation is supported when the indirect effect is significant, regardless of whether the total or direct effect is significant (Hayes, 2022).

Mathematical Formulas

M1 model: M1 = i₁ + a₁·X + e₁ M2 model: M2 = i₂ + a₂·X + d₂₁·M1 + e₂ Y model: Y = i₃ + c′·X + b₁·M1 + b₂·M2 + e₃
Specific Indirect Effects: IE₁ (via M1 only) = a₁ × b₁ IE₂ (via M2 only) = a₂ × b₂ IE₃ (serial M1→M2) = a₁ × d₂₁ × b₂ Total Indirect Effect: IEtotal = IE₁ + IE₂ + IE₃
📊 Bootstrap Recommendation

Hayes (2009) recommends at least 5,000 bootstrap samples for stable confidence intervals of indirect effects. MedModr offers up to 10,000 samples. With 5,000+ samples, CIs are stable across runs.

Moderation (X × W → Y)

Tests whether the effect of X on Y depends on the level of a moderator W. Output includes the interaction coefficient b₃ (X×W), simple slopes at Low (−1 SD), Mean, and High (+1 SD) levels of W, and an annotated slopes plot.

1
Select Moderation

Click Moderation (X × W → Y).

2
Enter X, W, and Y

All three variables must have the same N.

3
Select mean-centering strategy

Mean Centering (All variables), Mean Centering (Only continuous variables), or No Mean Centering.

4
Run & interpret

If the b₃ coefficient is significant, moderation is present. Simple slopes at three levels of W are displayed with an annotated plot.

Mathematical Formulas

Moderation Model: Y = i + b₁·X + b₂·W + b₃·(X×W) + e
Simple Slopes at Three Levels of W: Low (−1 SD): θ = b₁ + b₃ × (W̄ − SDw) Mean (centered): θ = b₁ + b₃ × W̄ High (+1 SD): θ = b₁ + b₃ × (W̄ + SDw) Simple Slope SE: SE(θ) = √[Var(b₁) + W²·Var(b₃) + 2W·Cov(b₁,b₃)]

Mean-Centering Options

  • All variables centered: (X − X̄) × (W − W̄)
  • Continuous-only centered: Center continuous X and W; leave binary (0/1) variables raw
  • No centering: Raw X × Raw W

Moderated Mediation (Conditional Process)

Tests whether the indirect effect of X on Y through M differs across levels of a moderator W. Select the moderation stage using the Moderation stage dropdown in the options row before running.

First Stage (X→M moderated) Second Stage (M→Y moderated) Both Stages

First Stage Moderated Mediation

W moderates the a-path (X → M). The effect of X on M depends on W. The b-path (M → Y) is unmoderated. Output includes: first-stage moderated regression, simple slopes of X→M at three levels of W, conditional indirect effects at each level, and the Index of Moderated Mediation (IMM = a₃ × b).

Mathematical Formulas — First Stage

Stage 1 (Moderated a-path): M = i₁ + a₁·X + a₂·W + a₃·(X×W) + e₁ Stage 2 (Unmoderated b-path): Y = i₂ + c′·X + b·M + e₂ Conditional a-path at level w: a(w) = a₁ + a₃·w Conditional Indirect Effect: IE(w) = (a₁ + a₃·w) × b Index of Moderated Mediation: IMM = a₃ × b
Conditional IEs at ±1 SD and Mean: IE(Low) = (a₁ − a₃·SDw) × b IE(Mean) = a₁ × b IE(High) = (a₁ + a₃·SDw) × b
📊 Index of Moderated Mediation — First Stage

The IMM (= a₃ × b) quantifies the linear change in the indirect effect as W changes by one unit. A bootstrap CI that excludes zero indicates statistically significant moderated mediation (Hayes, 2015).

Mathematical Formulas — Second Stage

W simultaneously moderates both the a-path (X → M) and the b-path (M → Y). Output includes both moderated regression tables and two interaction coefficient cards — one per stage.

Statistical Methods

This section documents the exact mathematical procedures MedModr uses for all computations. These are the same methods used in R, Stata, SPSS, and Hayes' PROCESS macro.

OLS Regression (Matrix Algebra)

All regressions in MedModr are computed using Ordinary Least Squares (OLS) via matrix algebra — the same method used in R (lm()), Stata (regress), and SPSS GLM.

Coefficients: β = (X′X)⁻¹X′y Residual Variance: MSE = Σ(yᵢ − ŷᵢ)² / (n − k − 1) Standard Errors: SE(βⱼ) = √[MSE × (X′X)⁻¹ⱼⱼ] t-Statistic: tⱼ = βⱼ / SE(βⱼ), df = n − k − 1 Confidence Interval: CI = βⱼ ± t(α/2, df) × SE(βⱼ) R-squared: R² = 1 − [Σ(yᵢ − ŷᵢ)² / Σ(yᵢ − ȳ)²] Adjusted R²: R²adj = 1 − (1 − R²)(n − 1)/(n − k − 1) F-Statistic: F = (R²/k) / ((1 − R²)/(n − k − 1))

Matrix inversion uses Gaussian elimination with partial pivoting. Matrices with near-zero determinants (severe multicollinearity) return an error rather than silently unreliable estimates. A singularity threshold of 1×10⁻¹⁴ is applied.

Standardized Coefficients (β)

Every regression table includes both unstandardized b and standardized β. Standardized coefficients are obtained by re-running the same regression on z-scored variables (mean = 0, SD = 1 for all predictors and the outcome). This matches the approach used in PROCESS macro v4.2.

z-score: zₓ = (x − μₓ) / σₓ | z_y = (y − μ_y) / σ_y Then: β = (Zₓ′Zₓ)⁻¹Zₓ′z_y
📚 Interpretation

A one standard deviation change in X produces a β standard deviation change in Y. Standardized coefficients allow direct comparison of effect sizes across predictors measured in different units. Both b and β are reported for every path in all models.

Bootstrap Confidence Intervals

For all indirect effects (simple, serial, conditional, IMM), MedModr implements the percentile bootstrap method — identical to boot::boot.ci(type="perc") in R and the default bootstrap CI in PROCESS macro. User-selectable resamples: 1,000, 5,000, or 10,000.

Step 1: Draw B bootstrap samples (n observations with replacement). Step 2: For each sample b, compute θ̂ᵦ (e.g., a×b, a₃×b, a₁×b₃). Step 3: Sort all B estimates: θ̂(1), θ̂(2), …, θ̂(B). Step 4: For 95% CI: Lower = θ̂(0.025×B) Upper = θ̂(0.975×B)
📊 Why Bootstrap?

This method does not assume normality of the sampling distribution — a critical advantage for indirect effects, which are products of two regression coefficients and often non-normally distributed. If the bootstrap CI excludes zero, the indirect effect is significant at α = 0.05.

⚠️ Bootstrap Availability by Analysis

Bootstrap CIs are available for: Simple Mediation, Serial Mediation, First Stage Moderated Mediation (IMM = a₃ × b), and Second Stage Moderated Mediation (IMM = a₁ × b₃). Bootstrap CIs are not produced when Both Stages is selected — run First and Second stages separately to obtain bootstrapped CIs.

MedModr uses a seeded pseudo-random number generator (Mulberry32 algorithm). Setting the same random seed in the options row produces identical bootstrap CIs across runs, ensuring reproducibility for reporting purposes.

p-value Calculation

MedModr computes exact two-tailed p-values using the cumulative distribution function (CDF) of the t-distribution via the regularized incomplete beta function (Lentz continued fraction algorithm). Accurate to machine epsilon for df ≥ 1. Very large |t| values (>30) are handled correctly and return p < 0.001.

Regression coefficients: p = 2 × P(T > |t|) where T ~ t(df = n − k − 1) P(T > t) = 1 − Iₓ(df/2, 1/2) x = df/(df + t²), I = regularized incomplete beta function Sobel test (indirect effects, no bootstrap): p = 2 × [1 − Φ(|z|)] where Φ = standard normal CDF

Covariate (Control Variable) Handling

All specified covariates C₁, C₂, …, Cᵢ are automatically mean-centered and included in every regression model in the analysis chain.

a-path model: M = i₁ + a·X + Σγⱼ·Cⱼ + e₁ b-path model: Y = i₂ + c′·X + b·M + Σδⱼ·Cⱼ + e₂ Total effect model: Y = i₃ + c·X + Σθⱼ·Cⱼ + e₃

Covariates are mean-centered (Cⱼ − C̄ⱼ) to improve interpretability of the intercept and reduce multicollinearity with interaction terms.

Computational Validation

MedModr uses the same mathematical procedures as established statistical packages. Point estimates for all path coefficients agree with PROCESS macro v4.2 and R lm() within rounding error (±0.001).

Validated against PROCESS Macro v4.2

Coefficient estimates, standard errors, t-statistics, and p-values were compared against Hayes' PROCESS macro across all model types (simple mediation, serial mediation, moderation, moderated mediation). All agree within rounding error.

Identical matrix algebra to R and SPSS

The OLS estimator β = (X′X)⁻¹X′y is implemented via Gaussian elimination — algebraically identical to lm() in R and the OLS routine in SPSS. When the same dataset is used, MedModr and R agree to at least 10 significant decimal places on all point estimates.

Percentile bootstrap matches PROCESS default

Bootstrap CIs use the percentile method, identical to boot::boot.ci(type="perc") in R and the default bootstrap CI in PROCESS macro. Resampling is done with replacement from the observed data.

Sobel SE matches Preacher & Hayes (2004)

The Sobel standard error SE = √(b²·SEₐ² + a²·SE_b²) is implemented exactly as described in Preacher & Hayes (2004) — the first-order delta method approximation used in all major mediation tools.

Exact t-distribution p-values

p-values use the regularized incomplete beta function (Lentz continued fraction algorithm) for the t-distribution CDF. Not approximated. Computed to machine epsilon for all df ≥ 1.

Standardized β via full z-scoring

Fully standardized β coefficients are obtained by re-running each regression on z-scored variables. This matches PROCESS macro v4.2 and is distinct from partially standardized estimates.

Mean-centering follows Hayes (2022)

For interaction models, mean-centered X and W are used in the interaction term. This is consistent with Hayes (2022) Chapter 7 and prevents inflated multicollinearity between main effects and the interaction.

Conditional indirect effects computed analytically

For moderated mediation, conditional indirect effects IE(w) = a(w) × b are computed analytically at W = Mean − 1 SD, Mean, and Mean + 1 SD, matching Preacher, Rucker & Hayes (2007).

Binary Variables (Dummy Coding)

⚠️ Manual Dummy Coding Required

MedModr does not automatically convert categorical variables into dummy codes. All categorical predictors, including moderators and covariates, must be converted by the user into numeric 0/1 dummy variables before pasting data. For a categorical variable with k levels, create k−1 dummy variables. The reference group should be coded 0 on all dummies.

Limitations

📐
OLS only

All models use ordinary least squares regression. Multilevel, SEM, and non-linear modeling are not supported.

💲
Listwise deletion

Rows with missing values must be removed before pasting data. No built-in missing data imputation.

📦
Large N performance

Performance degrades with N > 5,000 due to client-side matrix inversion in the browser.

🡱
Manual dummy coding

Categorical variables must be converted into 0/1 dummy variables by the user before analysis.

📊
Minimum sample sizes

Simple mediation: n ≥ 50; Serial mediation: n ≥ 100; Moderation: n ≥ 80; Moderated mediation: n ≥ 200.

🔄
Both Stages moderated mediation

Bootstrap CIs and simple slopes plots are not produced. Run First Stage and Second Stage separately to obtain bootstrapped CIs for each IMM.

📑
No assumption testing

MedModr does not automatically test OLS assumptions (linearity, homoscedasticity, normality of residuals). These must be verified externally before interpreting results.
