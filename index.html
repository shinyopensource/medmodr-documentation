What is MedModr?

MedModr is a free, browser-based tool for running mediation, moderation, and conditional process analyses. Upload any data file, assign variables, pick an analysis type, and get results without installing any software. Everything runs locally in the web browser, so data never leaves the user device. MedModr was created to democratize access to the most commonly used conditional process models. Tools like the PROCESS macro for SPSS/SAS and R are powerful, but they require licensed software or a configured environment that many researchers especially those in low-resource settings simply don't have access to. MedModr covers the same core models and runs entirely in a browser, making these analyses available to anyone, anywhere, for free.

No Installation

Works on any device (Windows, Mac, Linux, Chromebook, and tablet). Just open it in a modern browser like Chrome, Firefox, Edge, or Safari.

100% Private

All computations happen locally in the user browser and nothing is sent to any server.

Import CSV or Excel

Upload .csv, .xlsx, or .xls files. The built-in data processing steps handle variable selection, missing values, data screening, and cleaning before analysis.

Export Results

Download complete analysis results as a formatted Word, PDF, or HTML document.

Key Features

15 Analysis Types

Simple mediation, parallel and serial mediation, moderation, and multiple moderated mediation variants.

Bootstrap CIs

Up to 10,000 bootstrap samples. Choose Percentile or Bias-Corrected (BC) method for indirect effects.

Interactive Path Diagrams

Auto-generated diagrams with coefficient overlays. Toggle color/B&W, show/hide values, download as high-resolution PNG/SVG.

Simple Slopes Plots

Plots the moderator's effect at −1SD, Mean, and +1SD. Downloadable as high-resolution PNG.

Missing Data Handling

7 imputation methods including PMM, Hot Deck, EM algorithm, and regression-based imputation.

Data Screening

Edit data, detect outliers (4 methods), check normality, view correlation matrices, and inspect histograms and QQ-plots.

Categorical Variables

Built-in dummy coding. Pick a reference category and encode with one click. No manual recoding needed.

Unstandardized & Standardized

Every regression table shows both unstandardized (b) and standardized (β) coefficients alongside VIF.

Export Results

Export individual or all results to a single formatted Word, PDF, or HTML document.

How It Works

MedModr has two main sections: Data Processing and Statistical Analysis. You move through them in order.

1
Process Your Data (7 steps)

Upload your file → select the variables you need → preview → check missing data → impute if needed → screen for issues → finalize. Only Upload and Select Variables are required; everything else is optional.

2
Send Data to Analysis

Click Proceed to Analysis on the Finalize step. This passes your cleaned data directly to the statistical analysis page.

3
Assign Variables

Click variable chips from the Available Variables pool into the role boxes: X, M, M2, Y, W, or Covariates.

4
Choose Analysis Type & Options

Select your analysis type, set the confidence level, number of bootstrap samples, centering preference, and moderation stage (if applicable).

5
Run & Export

Click ▶ Run Analysis. Browse your results, then export to a formatted document.

Managing Variables

Remove a single variable from a role box by clicking the ✕ next to its name. Click the Clear button on a box header to empty that entire box. The red 🗑 Clear All button resets everything at once (a confirmation dialog appears first).

Categorical Variables

If any of your assigned variables contain text values (e.g., "male"/"female", "treatment"/"control"), a Handle Categorical Variables button appears automatically. Click it to open the encoding modal where you can pick a reference category (coded as 0) and choose which levels to include as dummy variables. Click Apply Encoding and the app replaces the original variable with 0/1 dummies across all role boxes. A Reset Encoding button lets you undo this if needed.

Interpreting & Exporting Results

Every analysis starts with descriptive statistics and ends with a plain-language summary of the findings. In between, you'll see regression tables, path diagrams (where applicable), indirect effect tables (where applicable), and simple slopes plots (where applicable).

Regression Tables

Each table reports both unstandardized (b) and standardized (β) coefficients so you can see both the raw effect size and how variables compare to each other. Other columns include SE, t/z, p-value, confidence interval bounds (LLCI, ULCI), significance stars, and VIF for multicollinearity checking.

  • b — the raw coefficient, in the original units of the variables.
  • β — standardized coefficient, useful for comparing predictors measured in different units.
  • VIF — values above 5 suggest potential multicollinearity; above 10 is considered problematic.
  • Stars — * p<.05   ** p<.01   *** p<.001

Covariates (Control Variables)

Add any number of control variables to the Covariates box. They're automatically included in every regression model in the analysis chain.

Mean Centering

For analysis types that use interaction terms (moderations and moderated mediations), three centering options are available:

  • No centering — raw variable values are used as-is.
  • Continuous-only centered — only continuous variables are mean-centered; binary (0/1) variables stay raw.
  • All variables centered — all predictors are mean-centered, including binary variables (0/1).

Simple slopes tables always use mean-centered moderator values (−1SD, Mean, and +1SD) regardless of the centering option you choose.

Bootstrap Confidence Intervals

Bootstrap CIs are calculated for all indirect effects — simple indirect effects, serial indirect paths, conditional indirect effects at moderator levels, and the Index of Moderated Mediation (IMM).

Two methods are available:

  • Percentile (default) — uses the raw percentiles of the bootstrap distribution. If the CI doesn't include zero, the effect is significant at your chosen alpha level.
  • Bias-Corrected (BC) — adjusts for systematic bias using the proportion of bootstrap estimates that fall below the observed estimate.

Recommended: 5,000 samples with the Percentile method for reliable, stable CIs.
