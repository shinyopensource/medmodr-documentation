What is MedModr?

MedModr is a free, browser-based, open-source application for mediation, moderation, and conditional process analysis. Tools like the PROCESS macro for SPSS/SAS and R are powerful, but they require licensed software or a configured environment that many researchers especially those in low-resource settings simply don't have access to.

MedModr was created to democratize access to the most commonly used conditional process models. It provides an accessible alternative by offering a no-cost, browser-based platform that requires no installation, licensing, or coding skills. All analyses are performed locally within the user's browser, ensuring data privacy and security. The application currently supports 15 widely used PROCESS models, with ongoing development aimed at expanding model coverage and enhancing functionality to meet the evolving needs of the research community.

No Installation

Works on any device (Windows, Mac, Linux, Chromebook, mobile devices, and tablet). Just open it in a modern browser like Chrome, Firefox, Edge, or Safari.

100% Private

All computations happen locally in the user browser and nothing is sent to any server.

Key Features

15 Analysis Types

Simple mediation, parallel and serial mediation, moderation, and multiple moderated mediation variants.

Bootstrap CIs

Up to 10,000 bootstrap samples. Choose Percentile or Bias-Corrected (BC) method for indirect effects.

Interactive Path Diagrams

Auto-generated diagrams with coefficient overlays. Toggle color/B&W, show/hide values, download as high-resolution PNG/SVG.

Simple Slopes Plots

Plots the moderator's effect at −1SD, Mean, and +1SD. Downloadable as high-resolution PNG.

Missing Data Handling

7 imputation methods including PMM, Hot Deck, EM algorithm, and regression-based imputation.

Data Screening

Edit data, detect outliers (4 methods), check normality, view correlation matrices, and inspect histograms and QQ-plots.

Categorical Variables

Built-in dummy coding. Pick a reference category and encode with one click. No manual recoding needed.

Unstandardized & Standardized

Every regression table shows both unstandardized (b) and standardized (β) coefficients alongside VIF.

Export Results

Export individual or all results to a single formatted Word, PDF, or HTML document.

How It Works

MedModr has two main sections: Data Processing and Statistical Analysis. You move through them in order.

1
Process Your Data (7 steps)

Upload your file → select the variables you need → preview → check missing data → impute if needed → screen for issues → finalize. Only Upload and Select Variables are required; everything else is optional.

2
Send Data to Analysis

Click Proceed to Analysis on the Finalize step. This passes your cleaned data directly to the statistical analysis page.

3
Assign Variables

Click variable chips from the Available Variables pool into the role boxes: X, M, M2, Y, W, or Covariates.

4
Choose Analysis Type & Options

Select your analysis type, set the confidence level, number of bootstrap samples, centering preference, and moderation stage (if applicable).

5
Run & Export

Click ▶ Run Analysis. Browse your results, then export to a formatted document.

Analysis Types & Variable Assignment

All 15 analysis types are run from the same Variable Assignment panel. The table below shows which variables each type needs and what it tests.

Analysis Type Model # Required Variables What it tests
Simple Mediation 4 X (1)M (1)Y (1) Does M carry the effect of X on Y? Includes Sobel test.
Parallel Mediation 4 X (1)M (2+)Y (1) Multiple mediators acting simultaneously. Reports individual and total indirect effects.
Serial Mediation 6 X (1)M₁ (1)M₂ (1)Y (1) Chain: X → M₁ → M₂ → Y. Tests three indirect paths. Includes Sobel test.
Simple Moderation 1 X (1)Y (1)W (1) Does W change how X affects Y? X×W interaction + simple slopes plot.
Double Moderation 2 X (1)Y (1)W (2) Two separate moderators W and Z. X×W and X×Z interactions.
Moderated Moderation 3 X (1)Y (1)W (2) Three-way interaction: X × W × Z → Y. All two-way interactions included.
Mediation with Moderated Direct 5 X (1)M (1)Y (1)W (1) W moderates only the direct X→Y path (c′-path).
W moderates X→M 7 X (1)M (1)Y (1)W (1) First-stage moderation: W moderates the X→M (a) path.
W moderates M→Y 14 X (1)M (1)Y (1)W (1) Second-stage moderation: W moderates the M→Y (b) path.
W moderates X→M & M→Y 58 X (1)M (1)Y (1)W (1) W moderates both the a-path and b-path.
W moderates X→M and X→Y 8 X (1)M (1)Y (1)W (1) W moderates both the a-path (X→M) and the direct path (X→Y).
W moderates M→Y & X→Y 15 X (1)M (1)Y (1)W (1) W moderates both the b-path (M→Y) and the direct path (X→Y).
W moderates X→M, M→Y, & X→Y 59 X (1)M (1)Y (1)W (1) W moderates all three paths: X→M, M→Y, and X→Y.
W moderates X→M, Z moderates M→Y 9 X (1)M (1)Y (1)W (2) Two different moderators: W on the a-path, Z on the b-path.
Moderated Serial Mediation 83 X (1)M₁ (1)M₂ (1)Y (1)W (1) W moderates X→M₁ within a serial chain: X→M₁→M₂→Y.
Variable Role Legend
X Independent Variable M Mediator(s) M₂ Second Mediator (serial only) Y Outcome Variable W Moderator(s) Cov Covariates (any number)
