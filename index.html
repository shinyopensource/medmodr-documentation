The Motivation Behind MedModr

Advanced mediation, moderation, and conditional process analyses are increasingly used across the health, social, behavioral, and educational sciences. Although powerful analytical tools such as the PROCESS macro for SPSS and SAS, as well as implementations in R and Python, are widely available, they often require licensed software, installation of programming environments, or proficiency in coding. These requirements can create significant barriers for many researchers, particularly students, early-career investigators, and researchers in low- and middle-income countries, where access to commercial software, high-performance computing resources, or advanced programming training may be limited. As a result, many researchers face unnecessary challenges in conducting rigorous statistical analyses and producing reproducible research.

MedModr was created to remove these barriers and make advanced statistical analyses accessible to everyone. It is a completely free, open-source, browser-based application that requires no software installation, licensing, account creation, or programming experience. Through an intuitive interface, users can upload their data, select the appropriate analytical model, and generate publication-ready results directly within a modern web browser. By eliminating technical and financial obstacles, MedModr enables researchers, educators, clinicians, and students to perform sophisticated mediation, moderation, and conditional process analyses with greater ease and confidence.

Key Features

File Formats & Offline Use

CSV files work entirely offline with no internet connection at all. Excel files need an internet connection only the first time you import one, while the SheetJS library used to read .xlsx loads. After that initial load, you can keep working with the data fully offline.

15 Analysis Types

Simple mediation, parallel mediation, serial mediation, simple moderation, moderated moderation, double moderation, and multiple moderated mediation variants covering most common conditional process analysis needs.

Bootstrap Confidence Intervals

Up to 10,000 bootstrap samples with Percentile or Bias-Corrected (BC) method for indirect effects. Provides bootstrap standard errors and confidence intervals around all estimates. Bootstrapping uses a seeded pseudorandom number generator (Mulberry32, default seed = 12345), so results are fully reproducible across operating systems, browsers, and devices.

Interactive Path Diagrams

Auto-generated SVG diagrams with coefficient overlays for eight (8) of the supported models. Toggle color/B&W, show/hide values or p-values, switch between unstandardized (b) and standardized (β) coefficients, rename variables, and download as high-resolution PNG or SVG for publications.

Simple Slopes Plots

Interactive Canvas-based plots of the moderator's effect at −1SD, Mean, and +1SD. Choose between a legend or on-line annotations, switch between default and publication-ready styling, and download as high-resolution PNG for manuscript preparation.

Missing Data Handling

7 imputation methods (mean, median, mode, Predictive Mean Matching (PMM), hot deck, regression-based imputation, and the EM algorithm) for handling incomplete data before analysis. The app also supports custom missing-value codes (e.g., −999, NA) and listwise deletion.

Data Screening

Edit data directly in the browser, detect outliers using 4 different methods (Z-score, IQR, MAD, percentile), check normality via skewness and kurtosis, view Pearson/Spearman/Kendall correlation matrices, and inspect histograms and Q-Q plots for data quality assessment, each exportable as a PNG.

Categorical Variables

Built-in dummy coding support. Pick a reference category and encode with one click. No manual recoding needed, and a "Reset Encoding" option restores the original variable.

Standardized & Unstandardized Coefficients for Mediation

Every regression table for mediation models shows both unstandardized (b) and standardized (β) coefficients alongside Variance Inflation Factor (VIF) statistics for multicollinearity checks. (Moderation and moderated-mediation outputs report unstandardized coefficients and VIF only.)

Export Results

Export a single analysis to a formatted Word (.doc), PDF, HTML, or CSV (Data) document ready for publication or presentation. When running multiple variable combinations, use "Export All to Word" to compile every result into one publication-ready document.

How It Works

MedModr follows a straightforward two-stage workflow designed to guide you from raw data to publication-ready results.

Stage 1: Data Processing

Detailed Steps

1Upload Data
2Select Variables
3Preview Data
4Missing Data Summary
5Choose Imputation
6Data Screening
7Finalize

Only Upload and Select Variables are required; other steps are optional but recommended for data quality.

Stage 1 walkthrough — upload, preview, and screen your data before running any analysis.

Stage 2: Statistical Analysis

  1. Variable Selection: Choose your dependent, independent, mediator, moderator, and covariate variables
  2. Model Selection: Choose from 15 PROCESS-equivalent models
  3. Run Analysis: Set bootstrap samples, confidence level, and centering preferences
  4. Review Results: Browse regression tables, path diagrams, and simple slopes plots
  5. Export: Download results as formatted Word, PDF, or HTML documents

Analysis Types & Variable Assignment

All 15 analysis types are run from the same Variable Assignment panel. The table below shows which variables each type needs and what it tests.

Variable Assignment panel — the same interface drives all 15 analysis types.
Analysis Type Model # Required Variables What it tests
Simple Mediation4X, M, YDoes M mediate the effect of X on Y? Includes the Sobel test.
Parallel Mediation4X, M (2+), YMultiple mediators operating simultaneously. Reports individual and total indirect effects.
Serial Mediation6X, M₁, M₂, YChain mediation: X → M₁ → M₂ → Y. Tests three indirect pathways.
Simple Moderation1X, Y, W (1; W only)Does W change the effect of X on Y? Includes the X×W interaction and simple slopes.
Double Moderation2X, Y, W (2; W & Z)Two separate moderators, W and Z. Includes X×W and X×Z interactions.
Moderated Moderation3X, Y, W (2; W & Z)Three-way interaction: X × W × Z → Y. Includes all two-way interactions.
Mediation with Moderated Direct Effect5X, M, Y, W (1; W only)W moderates only the direct X→Y path (c′ path).
W Moderates X→M7X, M, Y, W (1; W only)First-stage moderation: W moderates the X→M (a) path.
W Moderates M→Y14X, M, Y, W (1; W only)Second-stage moderation: W moderates the M→Y (b) path.
W Moderates X→M & M→Y58X, M, Y, W (1; W only)W moderates both the a-path and the b-path.
W Moderates X→M and X→Y8X, M, Y, W (1; W only)W moderates both the a-path (X→M) and the direct path (X→Y).
W Moderates M→Y & X→Y15X, M, Y, W (1; W only)W moderates both the b-path (M→Y) and the direct path (X→Y).
W Moderates All Three Paths59X, M, Y, W (1; W only)W moderates the X→M, M→Y, and X→Y paths.
W Moderates X→M, Z Moderates M→Y9X, M, Y, W (2; W & Z)Two different moderators: W on the a-path and Z on the b-path.
Moderated Serial Mediation83X, M₁, M₂, Y, W (1; W only)W moderates the X→M₁ path within the serial chain X→M₁→M₂→Y.
Notes

Variable notation:

  • W (1; W only) — Requires one moderator variable (W).
  • W (2; W & Z) — Requires two moderator variables (W and Z).

You can add any number of covariates to control for confounding variables in all analysis types.

Want to Contribute?

Contributions from the community are welcome and appreciated. Whether you are fixing bugs, implementing new features, improving documentation, or suggesting enhancements, your contributions help improve MedModr.

The preferred way to contribute is by opening a pull request on the GitHub repository. Before contributing, please read the CONTRIBUTING.md guide for information on the contribution workflow, coding standards, and submission guidelines.

OR

You may also send a description of the bug to mudassiribrahim30@gmail.com.

Helpful to Include

The analysis type you were running, your browser and version (e.g., Chrome 125, Firefox 127), a short description of what you expected vs. what happened, and if possible an anonymized sample dataset that reproduces the issue.
